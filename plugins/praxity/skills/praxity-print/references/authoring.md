# Choose a PDF recipe

Choose by the reader's task. Write the document's own Markdown and save layout choices in its JSON sidecar. These recipes guide writing and review; all use the same renderer.

Decide whether the reader needs support during a task, practice with feedback, or an assessment of a defined skill. Put needed answers within reach in a support aid. Offer examples when they help practice. In an assessment, preserve the intended recall or judgment demand while removing unrelated reading and layout difficulty.

## Illustrated procedure

Use when someone must carry out an ordered task. Give the starting state, needed materials, numbered actions and a visible result. Put warnings before the affected action. State what to do when a check fails. Keep the action, its image and result near each other; inspect page breaks after rendering.

Show the relevant object, action and end state. Keep the viewpoint consistent or explain a change. Check arrows, parts and movement for accuracy, especially in generated images. Give essential visual information an equivalent in text; picture-only instructions need audience testing.

Use a still image and text to explain a step that was shown in video. Keep essential instructions on paper. Ask a novice to do the task and record where they need help.

## Reference job aid

Use when someone needs to find an answer or choose a next action. Organize by likely questions or observed conditions. Use a table for comparable cases, with clear criteria and exceptions. Keep a supported contact or escalation route when needed. Give a graphical decision path an equivalent text route.

Give optional online resources a clear label and a readable address on paper. Test with cases that use different words from the headings.

## Checklist

State whether the reader acts from the list or checks work already done. For an action list, say what to do and when to mark it done. For verification, name the state to inspect. Split items when their conditions can fail separately. Define when an item may be marked not applicable, if that is allowed. Give a response to a failed check and a way to resume at the first unverified item. A checkmark must mean the stated condition was observed, not merely read. A printed marker is not a digital form control.

Keep the checks and failure response in the selected document. Test a missing item and an interruption. Use the pocket layout for a short reminder; inspect it at its actual size.

## Empathetic behavior prompt

Use for one feasible action at a clear moment or place. Lead with the action and give a brief reason that respects the reader. Check that the action is possible for the intended audience. Avoid shaming people who cannot comply or inventing statistics and claims about what most people do. Keep essential meaning visible without animation or a QR code.

Test what someone thinks it asks them to do, at the intended viewing distance. A preference rating cannot show behavior change. Save a type size suited to the viewing distance. A larger poster needs a separate layout review.

## Worksheet

State what the reader should produce and how they will use it. Give an example when it helps practice. Explain who will see the response and what happens next, such as feedback, revision or private reflection. Request only personal information needed for the task; offer a fictional case when disclosure is unnecessary. Match response space to the amount of writing requested. Keep each question with its response area, including at larger type sizes. Blank Markdown lines collapse. A single-column table with a label in its header and empty body rows provides full-width ruled writing space. Add empty rows to allow longer responses; keep other content outside that table.

Review a completed copy to check whether the prompts and space support the work. The printed tables are not fillable fields.

## Paper assessment

State the task, allowed resources, time and scoring criteria. Write the expected evidence before finalizing the question. Keep the participant document separate from any assessor key. Check visible text, image descriptions and PDF metadata for leaked answers; hiding a file from a menu does not exclude its contents from an authored document.

When presenting an assessed image in text would invalidate the task, use alternative text that identifies the image descriptively without supplying the answer. Choose an accommodation that preserves the assessed skill. This exception does not remove the need for an image alternative.

Score a few different responses. Check that the same rules apply to each. Clear layout alone cannot establish validity or fairness. Keep the assessor key separate and render only the requested file.

## Facilitator run sheet

For each segment, state how long it lasts. Give the reader task, leader action and cue for moving on. Use activity IDs that match the participant materials. Include setup and movement in the timing. Add a practical fallback for delay or unavailable media. If video explains an essential task, bring a local still and text version too.

Rehearse a late start and a failed display. Check that revised durations still fit. Calculate elapsed times from the stated start of the session.

## Participant session guide

Give the session purpose, sequence, preparation, activity instructions and next step. Match worksheet names and activity IDs. Keep facilitator production notes and assessor answers in separate files. Explain an offline route for any resource needed to finish the task.

Ask a participant to find the current activity and begin it. Check that the guide gives them what they need. Render the participant guide separately from the run sheet.
