# Rubato 0.2.0

Rubato 0.2.0 is the first public release. It runs on Apple Silicon and Intel
Macs. Windows support is planned for the next release. To install, see
[Install Rubato 0.2.0](../../README.md#install-rubato-020).

Studio opens courses written in grammar 4, the current version of Praxity's
course file format. If you open a course in the older grammar 3 format, Studio says "Grammar 3 is
no longer supported." The converter command in that message isn't publicly
available, so such a course can't be converted yet. A course that an earlier
Rubato's Studio opened is grammar 4 and still opens.

Import, which converts SCORM packages into Praxity courses, isn't included in
this release. It comes back once it writes grammar 4 courses.

## Update from an earlier version

1. Save your work in every Studio tab, close the tabs and stop Studio.
2. Run `praxity update`. If you have Rubato 0.1.1 or earlier, which has no
   update command, follow the
   [install steps](../../README.md#install-rubato-020) instead.
3. Update refreshes your user skills, and the project skills of the folder
   you run it in. For each other project with project skills, run
   `praxity skills refresh --scope project` in that project. Then start a new
   session in your agent, so it picks up the refreshed skills, including the
   two new ones, `composer` and `assessment-writing`.
4. In each course you use with T3 Code, run `praxity init` again. Then, in T3's
   project Actions settings, delete each saved Praxity action and import it
   again from `t3.json`. The actions now set up course identity, the IDs Studio
   gives each lesson and block, before they open Studio or export.
5. Export each course you've published as HTML or SCORM again, and replace the
   published copy: upload the new SCORM package to your LMS, or replace the
   HTML files on your web host. This brings in the security fixes in exported
   pages listed under Fixes.

If a download, a check or the self-test fails during the update, your earlier
version stays active. If only the skill refresh fails, 0.2.0 stays active, and
the message names the command to run again.

To go back to your earlier version, follow
[Go back to the previous version](../../README.md#go-back-to-the-previous-version).
In short: save your work and stop Studio, run `praxity rollback`, run
`praxity skills refresh --scope user` (and `--scope project` in each project
with project skills), then rerun `praxity init` in your T3 courses and
reimport their actions.

## Changes that can stop an export

- Inline SVG `data:` images are now refused, because they can carry script.
  Use an image file, or a PNG or JPEG `data:` URL.
- HTML and SCORM exports refuse GIFs that flash rapidly, which can trigger
  seizures. The export names each GIF to replace.

## New

- `praxity update` installs the latest release.
- Two new skills. `composer` turns a brief into a course outline, then
  coordinates writing and review. `assessment-writing` helps you write
  multiple-choice questions: wrong answers drawn from common misconceptions,
  feedback for each answer, and checks that learners can't pick the right
  answer from clues in the wording.
- In Studio's review mode, you can find each comment on the course and mark it
  resolved.
- Lessons can show a group label above the first heading, such as "Module 1",
  and a time line, such as "About 10 minutes".
- Exported courses keep the result of a learner's last submitted answer until
  they submit again, including when they start a new attempt.
- If you copied Rubato's skills into a skills folder by hand, Rubato can take
  them over. See "Your own edits" under Skills in the README.
- `praxity init` hides Studio's identity and recovery files in VS Code's file
  explorer and search. Your own VS Code settings stay as they are.
- Add `--lang fr` to a Studio command to get all its messages, including
  errors, in French. For example: `praxity studio . --lang fr`.

## Fixes

- Skills you've edited are backed up to `~/.praxity/skill-backups/` before a
  refresh or uninstall replaces them.
- Rollback works on Intel Macs.
- A failed install or self-test puts back the version you had.
- SCORM courses no longer overwrite a learner's saved progress when they can't
  read it from the LMS, or when a save fails.
- Exported pages block script hidden in link addresses, in the questions
  learners choose from in a question group, and in the course settings stored
  in each page.
- Self-checks that learners must try before the next slide opens
  (`{deckGate=attempt}`) now export.
- Studio's editor:
  - shows saving and saved status beside the text you edit;
  - after you discard changes, shows that it's loading the updated page
    instead of showing the old text;
  - when a lesson file has an error, explains the error and lets you edit
    again once you or your agent fix the file;
  - when you type a bullet character such as `-` at the start of a list item,
    explains that it would start a new list item;
  - keeps long lesson titles from widening the page.
- When Studio's preview in T3 doesn't appear, the `studio-editor` skill
  explains why and how to open Studio another way.
- Check's `prepare-review` command, for example
  `praxity check prepare-review <exported course> --output <new folder>`,
  tries out the course's interactive parts (tabs, dialogs, forms, quiz
  choices) and gathers evidence for questions that fixed rules can't settle.
  The evidence includes course text, page structure and local file paths. It
  now goes to Codex only if you add `--reviewer codex` or `--tier inference`;
  otherwise Check writes it for you or your agent to review. Check also runs accessibility checks by
  default on PDFs, as it does on HTML.
- Trace reads UTF-16 JSON files, such as those Windows PowerShell 5.1 saves,
  and UTF-8 files that start with a byte-order mark.
- Trace's item-cue check asks whether a learner who doesn't know the subject
  could still pick the right answer from clues in a question. It prepares
  question sets for separate agents to answer. By default it now prepares only
  the masked set, where subject words in the question and answers are replaced
  with made-up words so only wording clues remain; this works for English
  courses. Add `--diagnostics` to also prepare an answers-only set and a
  cover-the-answers set. The `assessment-writing` skill runs these steps: ask
  your agent to check your questions for answer clues.
- Rubato installs Node 24.22.1.
- The installer and links now use the Rubato name. The command is still `praxity`.

## Known limit

If other people have user accounts on your Mac, any of those accounts can get
Studio's editing link while Studio is running. Run Studio only on a Mac whose
other accounts you trust. A fix is planned for the next release.
